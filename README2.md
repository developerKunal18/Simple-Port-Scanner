# Simple Port Scanner

A Python script that scans a range of ports on a given host.

## Description
This project checks which ports are open on a specified host using socket connections.

## Features
- Port range scanning
- Detects open ports
- Fast and simple implementation

## Technologies Used
- Python
- socket module

## How to Run
1. Clone the repository
2. Navigate to the project folder
3. Run:

   python port_scanner.py

4. Enter host and port range

## Example

Input:
google.com  
75  
85  

Output:
Port 80 is open
